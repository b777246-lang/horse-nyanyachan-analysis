# 福島の特注条件と馬場状態（2026-11-04）

追加条件はすべてAND。同点1位を含み、既存の全出走馬による順位計算を使います。

| 表示名 | 条件 |
|---|---|
| 福島芝1200内枠S特注 | 福島・芝1200m・1～4枠・S指数1位 |
| 福島芝1200内枠TUA特注 | 福島・芝1200m・1～4枠・TUA指数1位 |
| 福島ダ1700湿馬場arms特注 | 福島・ダート1700m・arms指数1位・稍重/重/不良 |
| 福島ダ1700湿馬場arms2特注 | 福島・ダート1700m・arms2指数1位・稍重/重/不良 |
| 福島芝1800単勝特注 | 福島・芝1800m・1～4枠・arms指数1位（指数値下限なし） |
| 福島芝2000特注 | 福島・芝2000m・arms指数90以上・1位（枠制限なし） |

芝2000mのarms指数90以上以外に指数値の下限はありません。開催日目・季節・騎手の制限は付けていません。
芝1800m・芝2000mの追加2条件に馬場状態の制限はありません。馬場状態が未取得でも判定します。
これら6条件はコメントのみ追加し、評価点への加点は0です。既存条件の加点・順位計算・S2は変更しません。

## 使い方

- Web版：左側の「馬場状態の取得・指定」で開催日・競馬場を選び、「JRA当日分を取得」。
- Tkinter版：上部の「馬場状態の取得・指定」。
- PySide6版：上部の「馬場状態」。
- 自動取得できない日・取得失敗時は、芝とダートを別々に選び「手動指定を適用」。
- 「未取得」を適用するとその値を解除します。良なら湿馬場の2条件は不成立、未取得なら判定保留です。
- 手動指定は選んだ開催日・競馬場の全レースに適用します。レースごとの過去馬場の再現機能ではありません。
- 馬場を変更すると、画面の特注コメントと以後のCSV/HTML出力を再判定します。取得済みオッズ・人気は保持します。
- 開催日・競馬場の特定には、CSV内の18桁TARGET IDが必要です。

## 取得元と有効範囲

JRA公式馬場情報 `https://www.jra.go.jp/keiba/baba/` が使用する
`/JRADB/accessJ.html`（`CNAME=pw01iwtS3/CD`）を参照します。
取得仕様は公式 `/keiba/baba/_js/baba2025.js` で確認しました。
競馬場のページとA/B/C枠の対応は固定せず、当週の公式掲載ページから照合します。
公式JSONの `kaisai_ymd`、芝 `ba_s`、ダート `ba_d` を検証します。

- 自動取得は日本時間の当日分だけ。翌日や過去日に今日の値を流用しません。
- 日付・競馬場・芝/ダートをキーに管理。芝が重でもダートへ流用しません。
- 自動取得値は15分で失効。天候変化時は再取得してください。
- 再取得開始時に対象日の対象場の旧値を解除。取得失敗・未公表・不正応答で旧値を使い続けません。
- 手動値は同じ開催日・競馬場・芝/ダートにのみ有効。出典は「手動」と表示します。
- 状態はセッション内のみで、アプリ再起動時は再指定が必要です。
- デスクトップは30秒ごとと出力操作時、Webは再実行時に失効を確認します。
- 含水率・クッション値から馬場状態を推測しません。
