# 中京4コースの特注条件（2026-11-10）

すべてAND条件。同点順位を含む全出走馬の既存順位を使い、絞り込み後の順位再計算はしません。

| 表示コメント | 条件 |
|---|---|
| ★中京芝2200特注★ | 中京芝2200m・arms2指数110以上・1位・1～4枠 |
| ★中京芝1600特注★ | 中京芝1600m・arms2指数110以上・1～3位・1～4枠 |
| ★中京ダ1900特注★ | 中京ダート1900m・TUA指数1位・良馬場 |
| ★中京ダ1400特注★ | 中京ダート1400m・arms2指数120以上・1～2位・1～4枠 |

年齢・クラス・季節・開催日目の制限は追加しません。
ダ1900mはTUA指数値の下限・枠番制限なし。芝2200m・芝1600m・ダ1400mには馬場状態の制限はありません。

4条件ともコメントのみを追加し、評価点への加点は0です。
既存コメントと併記し、画面・CSV・HTMLの既存経路へ反映します。CSVの星記号等の整形は既存仕様を維持します。

ダ1900mは既存の馬場状態取得・手動指定の値を使用し、良馬場と確認できない場合は成立しません。
別日・別場・芝の馬場状態は流用せず、未取得・期限切れの場合は馬場条件の判定を保留します。
良から稍重・重・不良に変わった場合は、通常の再判定でコメントを除去します。

Tk版とQt版は共通のデスクトップ判定を参照します。Web版は同じ条件を設定として登録します。
テストでは指数値の境界、枠1～8、順位境界、同点順位、良/湿馬場/未取得、
画面・CSV・HTMLへの表示、既存コメント・スコア保持を確認します。
